# scripts

Starter placeholders for future automation.

## Suggested next scripts
- `inventory_github.sh` — list org repos, teams, members, and selected settings
- `export_github.sh` — export issues/PRs/releases/wiki metadata
- `inventory_appcenter.sh` — list apps, groups, testers, and integrations
- `export_appcenter.sh` — export available build/distribution artifacts and logs

## Safety rules
- Do not hardcode tokens
- Use environment variables for credentials
- Write output to a dedicated export directory that is not committed
